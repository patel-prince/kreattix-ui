# @kreattix/ui

Single-package install for **Kreattix UI** — 67 Radix-powered components, 3-tier `KreattixProvider`, design tokens, and 82 readymade sections.

## Installation
```bash
npm install @kreattix/ui
```

## Usage
```tsx
import '@kreattix/ui/styles.css';
import { KreattixProvider, ThemeInitScript, Button, Dialog, generateColorScale } from '@kreattix/ui';
import { HeroCentered } from '@kreattix/ui/sections';
```
